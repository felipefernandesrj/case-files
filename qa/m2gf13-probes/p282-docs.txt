# Changelog

## 0.4.22 (M2 game feel, sprint 13: a locked question box that looks locked)
- When the question budget is spent or the game is over, the question box and the Ask button now look locked instead of looking ready (before, only the cursor over the box changed). They turn dark and muted with a dashed edge, show a not-allowed cursor, and the box reads "Out of questions" (PT "Sem perguntas") or, after the verdict, "Game over" (PT "Fim de jogo"). The muted text keeps a 9.8:1 contrast, above the AA 4.5:1.
- Both carry `aria-disabled="true"` while locked, and the lock clears on Start over, Try again and a new file. The placeholder follows a language switch. While an answer is on its way the cursor shows progress. Reduced motion turns the box transitions off.
- The terminal game (node src/cli.js) now uses the same budget: it prints "Questions left: 8 of 8" at the start and after every answer, and at zero it says "No questions left in this game. Name the culprit with: accuse <suspectId>" (PT with acusar) instead of a raw error with browser button names. Accusing still works after the last question.
- New test/ask-lock.mjs with 10 checks. The automated suite now has 265 checks.

## Web page and CLI: locked question box (M2 game feel sprint 13)
- Page: `renderAskLock()` sets `#ask-form.is-locked` and `data-lock` (`out` when the budget is spent, `over` after the verdict, which wins), the `#q` placeholder `LABELS[lang].outPlaceholder` ("Out of questions" / "Sem perguntas") or `overPlaceholder` ("Game over" / "Fim de jogo"), and `aria-disabled="true"` on `#q` and `#ask-btn`; an open game has no class, no placeholder and no aria-disabled. `setGameOver()` and `renderBudget()` call it, so Start over, Try again, a new file and a language switch refresh it.
- CSS: locked box and Ask use `--cf-ink-soft` background and `--cf-text-dim` text (9.81:1), a dashed `--cf-lamp-dim` edge (outline on the button, no layout shift), `cursor: not-allowed`, an italic placeholder at full opacity and a dimmed icon; `aria-busy` shows `cursor: progress`; reduced motion removes the box transitions.
- CLI: src/cli.js prints `budgetText(lang, left, budget)` after the session starts and after every answer; at zero, and for any later ask without calling the server, it prints a command line ("Name the culprit with: accuse <suspectId>", PT with acusar); a server `out_of_questions` is shown the same way instead of "Error:".

[OLD 9]
### Scoring
Each case gives you a small budget of questions (8 for The Vanishing Violin, 10 for The Night Train), shown under the question box as "Questions left". Only answered questions count. When none are left, Ask locks and the Name the culprit button takes you to Accuse. A correct accusation scores 100 points if you asked 3 questions or fewer. Each extra question reduces your score by 5 points. The minimum score is 10. A wrong accusation scores 0. The verdict will reveal the solution. Top scores appear on the scoreboard. Your own best score for each language is kept in your browser; use "Reset my best scores" to clear it (you will be asked to confirm). When you beat your best, the game says "New personal best!".
