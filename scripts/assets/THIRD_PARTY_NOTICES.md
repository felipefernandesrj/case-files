# Third-party notices: Case Files asset pipeline

The asset pipeline in `scripts/assets/` is local build tooling. It is not shipped to players.
The player only receives the finished PNG / WebP files. Model weights are downloaded into
the user cache on first use, checked against the pinned hash, and never committed.

## Primary method

`flood-key` in `bgremove.py` (border-sampled chroma key, edge flood-fill, pocket clearing, halo peel,
hard alpha) is original code in this repository. It follows the approach described by pixel-art tools
such as pixfix (MIT), Sprite Lab and Aseprite's magic wand; no code was copied from them.
